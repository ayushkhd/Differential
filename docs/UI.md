# Part 2 UI

Run from the repository root:

```sh
node web/dev-server.cjs
```

Open http://127.0.0.1:5173. Run the teammate-owned FastAPI backend on port 8000 in another terminal. No frontend dependencies or API keys are required. Override the proxy with `API_ORIGIN=http://127.0.0.1:8000`; override the UI port with `PORT=5174`.

The UI implements CONTRACTS.md Part 2: start/replay, one-second non-overlapping tile polling, clickable paired evidence, call audio, marketplace tabs and recorded offer chart, report counts from `/api/verdicts`, Semgrep findings and supplied generated rule, and GitHub issue remediation. A verdict stays pending until both sandbox sides are done. Replay is visibly labeled; backend fixtures are explicitly possible until real runs land. No results are generated by the UI.

The blast graph consumes `/api/blast` and preserves planned-family reasons. JSON import is local to the browser; analysis belongs to the backend owner. Opening `web/blast.html` directly provides an explicitly labeled PRD preview. The original standalone OpenAI analyzer remains in the parent workspace and is not part of the Part 2 backend contract.

Validation:

```sh
node --test tests/ui-core.test.cjs
node --check web/ui.js
node --check web/dev-server.cjs
```

The coding environment cannot bind a listening socket, so HTTP proxy/audio playback and a full live backend run must be checked on your machine. Audio failures are shown in the evidence panel. No GitHub issue is created until you click Send to remediation.
